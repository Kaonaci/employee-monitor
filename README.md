# employee Monitor

Небольшая утилита для периодического захвата изображений с экрана компьютера и веб-камеры. Может использоваться как основа для разработки инструментов мониторинга рабочего процесса сотрудника.

Проект создаётся в образовательных целях и может содержать недоработки. Текущая реализация не претендует на полноценный промышленный инструмент.

> Использование для мониторинга сотрудников должно осуществляться прозрачно, с предварительным уведомлением и соблюдением применимых требований законодательства о персональных данных.

## Configuration

Настройки приложения задаются в файле `config.yaml`:

```yaml
screen_dir: ./screenshots
camera_dir: ./camera_frames
interval_seconds: 180
```

| Параметр | Описание | По умолчанию |
|---|---|---|
| `screen_dir` | Директория для сохранения снимков экрана | `./screenshots` |
| `camera_dir` | Директория для сохранения кадров веб-камеры | `./camera_frames` |
| `interval_seconds` | Интервал между циклами захвата в секундах | `180` |

Указанные директории будут созданы автоматически при запуске приложения, если они ещё не существуют.

## Installation

Для работы приложения необходим Python и зависимости из `requirements.txt`.

### Wayland

Для захвата экрана в Wayland необходимо предварительно установить утилиту `grim`.

Например, в Arch Linux:

```bash
sudo pacman -S grim
```

### Python dependencies

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone https://github.com/Kaonaci/employee-monitor
cd employee-monitor
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Linux:

```bash
source .venv/bin/activate
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Launch

Перед запуском убедитесь, что файл `config.yaml` находится в корневой директории проекта.

Запуск приложения:

```bash
python -m src.main
```

Для завершения работы используйте `Ctrl+C`.
